## Target Audience

Thai children ages 10-12 in the upper primary / early secondary school range. They can read simple Thai and English text, follow basic game rules, and handle slightly more complex interactions than the 8-10 age group. Topics are chosen to match their real-world interests: technology, social media concepts, sports, science, and future aspirations.

## Page Types Per Unit

Each unit gets 7 page types (same as children_8_10 pattern):

| Page Type | Assignment | Description |
|-----------|-----------|-------------|
| Story | every | 6-page bilingual story with comprehension questions |
| Game | every | 3 tabs: Match, Scramble, Spelling |
| Song | every | YouTube embed + bilingual lyrics + fill-in-the-blank |
| Reading | every | Thai vocab passage + English reading + comprehension |
| Flashcards | every | Flip cards with emoji front, word+Thai+definition back |
| Quiz | every | 10 mixed questions (match, fill, MCQ, word order) |
| Reward | every | Celebration page with confetti + word review |

**Total files: 12 units x 7 page types = 84 HTML files**

## File Naming Convention

Pattern: `explorers_{topic}_{pagetype}.html`

Examples:
- `explorers_technology_story.html`
- `explorers_technology_game.html`
- `explorers_travel_flashcards.html`
