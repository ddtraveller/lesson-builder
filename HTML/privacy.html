Privacy Policy

Lesson Builder — Claude Code Skill
Last updated: March 25, 2026

What Lesson Builder Is

Lesson Builder is a skill for Claude Code that generates standalone bilingual course pages (HTML/CSS/JS). It runs locally on your machine inside the Claude Code environment. It does not operate a server or collect data from end users of the generated pages.

Data the Generated Pages Store

Pages created by Lesson Builder may store data locally in the user's browser:

Generated pages contain no cookies, no analytics, no tracking pixels, and no user accounts.

Optional Integrations Used During Generation build-time only

These services are used only during course generation inside Claude Code — not by end users viewing the pages. All are optional and require explicit configuration.

Your API tokens for these services are stored locally (in .env files or environment variables) and are never embedded in generated pages.

Web Search

When web search is enabled, the skill may search the web during generation to verify course content (vocabulary definitions, grammar rules, subject matter accuracy). Search queries contain course topics and are processed by the search provider configured in Claude Code. No end-user data is involved.

Data We Collect

None. Lesson Builder is an open-source skill that runs locally. We do not operate servers, collect telemetry, or receive any data from you or your users.

Children's Privacy

Lesson Builder generates educational content that may be used by learners of all ages. The generated pages do not collect any personal information from children or any other users.
